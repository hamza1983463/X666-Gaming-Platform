# H666 Gaming Platform 🎮

A color prediction gaming platform built with HTML, CSS, and JavaScript. Play Red or Green and win PKR!

## Features ✨

- 🎨 **Color Prediction Game** - Choose Red or Green
- 💰 **PKR Balance System** - Start with 1000 PKR
- 🎯 **Real-time Results** - Instant win/loss feedback
- 📱 **Responsive Design** - Works on all devices
- 🌙 **Dark Theme** - Modern UI with smooth animations
- 🇵🇰 **Urdu Support** - Game instructions in Urdu

## How to Play 🎮

1. Choose either **Red** or **Green**
2. Enter your betting amount (must be less than your balance)
3. Click **"Play Now"** button
4. Win = Your bet amount is added to balance
5. Lose = Your bet amount is deducted from balance

## Files 📁

- `H666.html` - Main game file

## How to Run 🚀

Simply open `H666.html` in any web browser!

## Tech Stack 🛠️

- HTML5
- CSS3
- Vanilla JavaScript
